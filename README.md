# MovieExplorer

A movie and TV show browsing website made with React. You can browse shows, search by title, and view more information about each show.

## Features

- Home page with navigation and an Explore button
- Browse TV shows from TVMaze
- Search shows by name
- Responsive show cards
- Details modal with the show summary, rating, release date, and genres
- Loading, error, and no-results messages

## Built With

- React
- React Router
- Tailwind CSS
- DaisyUI
- TVMaze API

## Running the Project

Install the packages first:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Other useful commands:

```bash
npm run dev
npm run build
npm run lint
npm run preview
```

## API

This project uses these TVMaze endpoints:

- `https://api.tvmaze.com/shows`
- `https://api.tvmaze.com/search/shows?q=:query`
